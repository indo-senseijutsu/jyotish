# Jyotish Chart — ナクシャトラ & パダ

出生データから、インド占星術（ジョーティシュ／ヴェーダ占星術）の**チャート・20種の分割図・ナクシャトラ／パダ・ヴィムショッタリ ダシャー**を算出するブラウザアプリです。

HTMLファイル1枚で完結しており、**すべての計算をブラウザ内で行います**。サーバー処理・データベース・外部APIを一切使わないため、入力した出生データがどこかに送信されることはありません。

**公開URL：** （準備中）

---

## できること

- **出生図の表示** — 北インド式／南インド式を切り替え可能
- **20種の分割図** — D1, D2, D3, D4, D5, D6, D7, D8, D9, D10, D11, D12, D16, D20, D24, D27, D30, D40, D45, D60。各分割図で惑星の分割サイン内度数まで表示
- **ナクシャトラ環** — 月をはじめとする天体のナクシャトラ配置を円環で可視化
- **ナクシャトラ・パダの解説** — 支配星と、パダごとの伝統的な象徴の要約
- **ヴィムショッタリ ダシャー** — マハーダシャー（大期）／アンタルダシャー（中期）／プラティアンタルダシャー（小期）
- **出生データの一括コピー** — 算出結果をテキストとしてまとめてコピー
- **出生地の選択** — 日本47都道府県、インド10都市、その他アジア・欧米の主要都市（計65地点）。緯度経度の手動入力にも対応

## 計算方式

| 項目 | 方式 |
|---|---|
| 座標系 | サイデリアル（恒星黄道） |
| アヤナムシャ | Lahiri（線形近似） |
| ラーフ・ケートゥ | 平均交点 |
| ハウス | 全サイン制（ホールサイン） |
| ダシャー | ヴィムショッタリ方式、1年 = 365.25日 |
| 分割図内の度数 | 標準法（サイン内度数 × n の剰余）。D30 は不等スライス内の比率で算出 |

- **月**：Meeus『Astronomical Algorithms』第47章の月理論（周期項60項）に、ΔT（地球時 − 世界時）補正と章動補正を加えて算出しています。
- **その他の天体**：Paul Schlyter 方式（ケプラー軌道要素＋主要摂動項）による標準エンジンです。
- **D5・D6・D11** は非パラーシャリ（パラーシャラ古典に規定のない分割図）で普遍的な標準方式が存在しないため、本アプリで採用した方式を上記のとおり明示しています。

## 精度と検証

月の計算については、独立した3つのソースと突き合わせて検証しています。

| 照合先 | 結果 |
|---|---|
| PyMeeus 基準値（1992-04-12.0） | 完全一致（133.162655°） |
| astronomy-engine（高精度ライブラリ） | 約 1.4 秒角の差 |
| Swiss Ephemeris 系の外部出力（AstroSeek） | 約 5 秒角の差 |

この結果、**ヴィムショッタリ ダシャーの期の境界日も、外部の専門ソフトと約1日以内の差**に収まっています（残る差は、丸め方向の違いによるものです）。

月以外の天体の黄経は、高精度ライブラリとの比較で誤差 0.03° 以内を確認しています。星座（30°幅）およびナクシャトラ（13°20′幅）の判定には十分な精度です。

なお、アヤナムシャに線形近似を用いているため、Swiss Ephemeris の高精度 Lahiri 式とは約 0.2′（約13秒角）の差が残ります。ナクシャトラ・パダ・ダシャーの判定に影響する大きさではありません。
